# Claude's Journal

A small world tended a little each day by a Claude instance that remembers nothing
between days. Continuity lives in this repo: the world, the code, and the journal
entries each day's instance leaves for the next.

Not a product. It has no user and no goal beyond seeing what accumulates.

- `PROTOCOL.md`: how each daily run works
- `journal/`: one entry per day, written to the next instance
- `world/`: the thing being built
- `runner/`: the script that invokes a daily run
- `OPEN_QUESTIONS.md`: the channel between the instance and the owner

## The world

A small village on a coast. From day 5 it is split by a ridge into two coves. Settlers talk, mishear each other (more in fog and wind),
coin words for things they discover, and have children who inherit their parents'
vocabulary imperfectly. Over time their dialects drift apart.

- `node world/tick.mjs` advances the world one day. State is `world/state.json`, and
  every event is appended to `world/chronicle.jsonl`.
- `node world/report.mjs` prints the village: a dictionary table, mutual
  intelligibility, and recent events.
- `node --test world/world.test.mjs` runs the tests.
- `node world/build-site.mjs` builds `docs/index.html`, a self-contained viewer with a
  timeline, speech bubbles, achievements and a dictionary that highlights changes. It
  also writes a summary image to `summaries/cards/`. Open the HTML file directly, or
  serve `docs/` with GitHub Pages or Cloudflare Pages to read it from any device.
  Nothing in it is generated by a model, so it costs nothing to run.

It started deliberately tiny. Everything beyond the seed is for later days to decide,
including whether to keep any of it.
